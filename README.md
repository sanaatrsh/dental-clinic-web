# 🦷 الكنج — نظام إدارة مرضى العيادة السنية

## هيكل المشروع

```
dental-clinic/
├── index.html          ← الملف الرئيسي (HTML فقط)
├── css/
│   └── style.css       ← جميع أنماط التصميم (CSS)
├── js/
│   ├── app.js          ← المنطق الأساسي (إدارة المرضى، الجلسات، الدفع...)
│   └── analytics.js    ← التحليلات، التقويم، الخطط العلاجية، الرسوم البيانية
└── README.md           ← هذا الملف
```

## كيفية الاستخدام

افتح ملف `index.html` مباشرة في المتصفح. الملفات مترابطة تلقائياً.

## الملفات الخارجية المستخدمة

| المكتبة | الغرض |
|--------|--------|
| Google Fonts (Cairo, Tajawal) | الخطوط العربية |
| Font Awesome 6.5 | الأيقونات |
| SheetJS (xlsx) | تصدير/استيراد Excel |
| Chart.js 4.4 | الرسوم البيانية في التحليلات |

## ملاحظات للمطور

- **`css/style.css`**: يحتوي على متغيرات CSS للوضع الليلي والنهاري، وكل أنماط المكونات
- **`js/app.js`**: يحتوي على حالة التطبيق (state)، إدارة المرضى، المدفوعات، النسخ الاحتياطي
- **`js/analytics.js`**: يحتوي على نظام التقويم، التذكيرات، الخطط العلاجية، والرسوم البيانية
- البيانات تُخزن في `localStorage` المتصفح
